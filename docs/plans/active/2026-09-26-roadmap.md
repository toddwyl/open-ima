## 跨计划接口契约(P1 产出,P2 消费)

```
POST http://parser:8100/parse
Request:  { "file_url": string, "file_type": "pdf"|"docx"|"pptx"|"md"|"txt"|"html" }
200:      { "title": string, "blocks": [ { "type": "heading"|"paragraph"|"list"|"table",
                                           "text": string, "level": int } ] }
422:      { "error": string }   # 不支持类型/加密/扫描件/损坏 —— 不可重试
502:      { "error": string }   # 拉取文件失败 —— 可重试
GET /health → { "status": "ok" }
```

## 全局约束(所有计划共用,逐条来自 spec)

- LLM/Embedding 仅通过云端 OpenAI 兼容 API;配置 `config.yaml` + `IMA_` 前缀环境变量覆盖
- 元数据 SQLite,Go 驱动用 `modernc.org/sqlite`(纯 Go,禁 CGO)
- 检索引擎 Meilisearch v1.x,embedding 以 `userProvided` 方式由后端写入
- parser sidecar 不下载任何模型权重;镜像目标 <200MB
- chunk 目标 ~500 token、overlap 50;worker 并发 4;job 重试 ≤3 次(1m/5m/15m)
- 提交前必跑 `./scripts/harness.sh`(P5 填实;此前各计划自行保证 lint+test 通过)
- 分支规范:每个计划在 `.worktrees/` 独立 worktree + `feat/<name>` 分支开发,完成合回 main(见 docs/spec/worktree-workflow.md)
